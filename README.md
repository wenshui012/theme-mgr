# 🎨 SillyTavern 美化管理器

> SillyTavern 主题美化管理扩展 —— 让你的 100+ 主题不再混乱

**作者：温水**

## ✨ 功能一览

- **一键切换主题** — 点击卡片即可切换，无需翻设置页面
- **导入美化** — 支持导入单个 ST 主题 JSON，美化会写入 ST 用户主题列表
- **批量导入/导出美化包** — 一次打包或导入多个美化，适合备份和社区分享
- **导入分类选择** — 导入美化时可选择导入哪些分类，也可指定导入后的本地分类
- **分类管理** — 自定义分类，把主题按风格、作者、用途归类
- **标签系统** — 每个主题可添加多个标签，搜索时更精准
- **收藏功能** — 星标你最爱的主题，收藏优先排序一键找到
- **预览截图** — 为主题添加截图，卡片展示一目了然
- **绑定背景** — 可为每个美化绑定 ST 已导入壁纸，切换美化时自动应用或取消背景
- **角色 / 聊天绑定** — 可让美化跟随某张角色卡或某个聊天窗口，聊天绑定优先并在离开后恢复手动美化
- **日夜美化** — 将日间版和夜间版合并为一张卡片，随系统深浅模式自动切换，也可在编辑面板临时手动切换
- **系列收纳** — 多选普通或日夜美化保存为系列，以横向滑道展示，并可原地展开、改名、换展示分类或安全解散
- **多种排序** — 按名称 / 最近使用 / 使用频率 / 收藏优先
- **搜索** — 支持搜索主题名、标签、作者、备注
- **网格缩放** — 主界面卡片可自由放大缩小，主题多时更容易浏览
- **批量操作** — 多选后批量分类、加标签、切换收藏
- **使用统计** — 自动记录每个主题的使用次数和最近使用时间
- **大图浏览** — Lightbox 模式浏览截图，支持左右切换
- **数据导出/导入** — 备份你的分类、标签、截图等标注数据
- **悬浮球** — 可拖拽、可自定义图片和大小的 FAB 按钮，随时打开管理器
- **明暗主题** — 管理器自身支持明/暗模式切换

## 📦 安装方法

### 方法一：通过 SillyTavern 扩展安装器

1. 打开 SillyTavern
2. 进入 **扩展** → **安装扩展**
3. 输入本仓库地址，点击安装

### 方法二：手动安装

1. 下载本仓库的 zip 文件
2. 解压到 `SillyTavern/data/default-user/extensions/` 目录下
3. 确保目录结构为：
   ```
   extensions/
    └── theme-manager/
        ├── index.js
        ├── manifest.json
        └── README.md
   ```
4. 刷新 SillyTavern 页面

### 开发与单文件发布构建

仓库开发入口仍是根目录 `index.js`，它按固定顺序加载 `src/` 下的拆分模块。正式发布候选由脚本生成，不手工修改生成文件：

```bash
node scripts/build-single-file.js
node scripts/verify-release.js
node -c dist/index.js
```

构建结果位于 `dist/`，包含可直接安装的 `index.js`、`manifest.json` 和 `README.md`。其中 `dist/index.js` 已内嵌全部 18 个模块，不再请求本扩展的 `src/*.js`；`src/` 与 `tests/` 继续作为开发和发布门禁源码保留。

### 可选：安装后端存储

如需把截图、缩略图、悬浮球图片和标注数据保存到后端，请额外安装 `theme-mgr-server` 后端仓库：

1. 下载或克隆 `theme-mgr-server`
2. 将后端文件夹复制到 `SillyTavern/plugins/theme-manager/`
3. 重启 SillyTavern
4. 打开美化管理器，插件会自动优先使用后端存储；后端不可用时会回退到浏览器本地存储

## 🚀 使用说明

- **打开管理器**：点击侧栏的「美化管理」按钮，或点击右下角悬浮球
- **切换主题**：直接点击主题卡片
- **管理主题信息**：点击卡片左下角的 `⋯` 菜单按钮，可以编辑、收藏、查看截图
- **调整预览构图**：编辑美化时可设置截图焦点和缩放；完整构图会保留，网格形状变化时只增减可见区域
- **绑定背景**：在主题编辑面板中点击「绑定背景」，从 ST 已导入壁纸中选择
- **绑定角色或聊天**：点击美化卡片的 `⋯` →「角色 / 聊天绑定」，可绑定或解除当前角色卡、当前聊天窗口
- **添加分类**：进入设置（底栏齿轮图标）→ 管理分类
- **批量操作**：点击底栏「多选」按钮进入批量模式
- **组成日夜美化**：在多选模式选择两个普通美化，点击「日夜」，指定日间版、夜间版和合并后的名称
- **组成系列**：在多选模式选择至少两个美化，点击「系列」设置名称和展示分类；系列标题可管理成员，右侧箭头可原地展开 / 收起
- **编辑日夜版本**：打开合并卡片的编辑面板，使用右上角太阳/月亮按钮切换正在编辑并应用的版本；手动选择会在系统模式变化、切换聊天或重新打开管理器时恢复自动
- **导入/导出美化**：进入设置 → 数据，可导入单个美化、批量导入美化或导出美化包
- **搜索**：点击顶栏搜索图标
- **排序**：点击顶栏排序图标，选择排序方式
- **刷新列表**：点击底栏刷新按钮，重新读取 ST 主题列表

## 💡 说明

- 管理器通过读取 SillyTavern 的主题列表来工作，切换美化时会调用 ST 的主题能力
- 安装 `theme-mgr-server` 后端后，分类、标签、截图、缩略图、角色/聊天绑定、悬浮球图片等数据会优先保存到后端；未安装后端时会回退到浏览器 IndexedDB
- 「导出标注 / 导入标注」会处理分类、标签、截图、角色/聊天绑定等附加数据，不修改 ST 主题文件
- 「导出美化包 / 导入美化」会读写 ST 用户主题 JSON，并尽量携带截图资源和分类标注，适合备份或社区分享
- 日夜美化在网格中显示为一张卡片，但美化包会同时导出两个真实主题及其日夜关系
- 系列只保存收纳关系，不复制或改动真实主题；成员顺序跟随当前排序，移出成员或解散系列都不会删除美化
- 绑定背景使用 ST 已导入的壁纸；切换到未绑定背景的美化时，美化管理器不会修改当前 SillyTavern 背景
- 聊天绑定优先于角色绑定；角色绑定适用于该角色的所有聊天。离开全部绑定范围后，会恢复最后一次手动选择的美化
- 在酒馆内保存新的角色头像时，管理器会随角色编辑事件迁移绑定；如果插件未加载时由外部工具直接替换角色文件，则需重新绑定

## 📝 更新日志

### v4.0.5（当前版本）

这是针对 TauriTavern 纯前端环境 metadata 保存失败的兼容性 hotfix。

#### 修复

- 识别 TT 官方运行时 ABI，在没有 Node 后端的环境中使用纯本地存储，不再探测不存在的主题管理后端接口
- 修复后端路由返回空内容或 HTML 时，作者、备注等编辑被误判为 `LOCAL_STATE_NOT_AUTHORITATIVE` 的问题
- 保存前仍会重新确认本地状态；本地主数据、同步状态或 revision 损坏时继续安全失败，不会覆盖不确定数据
- 原生 SillyTavern 保持原有严格后端校验，不受 TT 本地模式影响

### v4.0.4

这是针对部分 TT 用户 metadata 无法保存的安全 hotfix。

#### 修复

- 修复本地主数据和同步状态均尚未创建时，保存被误判为 `LOCAL_MAIN_INVALID` 的问题
- 仅在重新确认本地仍为空且后端无数据后允许初次保存；已有数据、部分缺失或无法确认状态时仍保持安全失败
- 补充空存储首次保存、状态变化、后端已有数据及后端不可确认等回归测试

### v4.0.3

这是一次以兼容性和数据保护为重点的 hotfix，并建立了从拆分源码生成单文件发布版的构建流程。

#### 修复

- 修复部分用户更新后所有主题都无法切换的问题，同时保留库存结构损坏和目标重名时的安全拦截
- 修复未绑定背景的美化会错误清空当前酒馆背景的问题；未绑定时不再修改 SillyTavern 当前背景
- 改进本地 metadata 保存失败诊断，增加稳定错误码、存储信息和复制诊断入口
- 修复启动阶段临时本地存储读取异常后，当前会话可能永久锁定写入的问题；保存前会进行一次安全 revalidation

> TT 故障用户现场尚未完成覆盖验证；本版本不会声称已解决所有 TT metadata 保存失败场景。

#### 发布构建

- 开发仓库继续保留拆分后的 `src/` 与测试；发布候选由 `scripts/build-single-file.js` 可重复生成到 `dist/index.js`
- 单文件发布版不再在运行时请求本扩展的 18 个 `src/*.js` 模块
